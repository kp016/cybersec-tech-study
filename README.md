## ✨ What's inside

- **📘 Theory notes** — clear, exam-focused summaries for every week
- **📝 Slide Practice quizzes** — questions pulled straight from the lecture slides & handouts, each with an explained answer
- **🧪 Lab / practical checklists** — tick items off as you work through the tutorials (progress saves in your browser)
- **✅ Checkpoint tests** — a bigger scored test after every two weeks, with recap + practical self-check
- **🖥️ VM cheat sheet** — IPs, logins and port forwards for the lab environment (Kali · Greenbone · Metasploitable2 · Win8)

## 🚀 How to use it

Just open the [live site](https://kp016.github.io/cybersec-tech-study/) in any browser — phone, tablet or laptop. No install, no login. Your quiz scores and checklist progress are saved locally in that browser.

To run it offline, download `index.html` and open it directly.

## 🔧 Built with

A single self-contained `index.html` — plain HTML, CSS and JavaScript, no frameworks or build step. Published free via **GitHub Pages**.

## 🧩 Extending it

All content lives in the `WEEKS` and `TESTS` JavaScript arrays near the top of the `<script>` block in `index.html`. To add Week 7+, copy an existing week object, update its content, and it appears in the navigation automatically.
